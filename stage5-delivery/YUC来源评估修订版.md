# YUC 来源评估修订版

本修订保留此前来源评估交付，不覆盖原目录；修订记录说明本轮对三处表述收紧。

## 修订后的实际批准边界

此前“附条件准入”只是一项评估建议，不是已授予真实采集许可。本轮实际批准范围仅为：**离线开发、合成 HTML Fixture、模拟网络响应和契约测试**。当前不批准真实来源 HTTP、真实样本保存、自动同步或公共展示。

## 修订后的字段边界

本轮只保留 YUC 来源页面 URL（例如 `https://yuc.wiki/new/`）作为 provenance。第三方资源链接、播放/下载链接、图片 URL、平台 URL 和任何外链元数据均不采集、不保存、不展示；候选契约没有 `externalLinks` 字段。

## 事实、项目限制与未验证事项

- 已验证事实：站点自称 `Yuc's Anime List / 長門番堂`，页面署名 `長門有C`，可见 BY-NC-SA 声明；常规 robots、条款和 API 入口在核验时未找到。
- 项目限制：离线优先、来源默认关闭、只用合成 Fixture、禁止第三方素材和公共展示，是 Menghuan 本轮治理边界，不是 YUC 站点要求。
- 未验证事项：运营主体、书面授权、具体第三方素材权利、机器访问政策、建议频率和部署是否满足 NonCommercial 条件。
- 解释边界：未找到 robots 或条款页面既不等于法律禁止，也不等于取得许可；联系主体、书面许可和机器访问政策是项目在进入真实采集前的准入待办，不冒充站点规则。

## 结论

评估建议仍为“附条件准入”，但当前状态是**只批准离线实现，不放行真实采集和公共展示**。真实来源验证需另行审查和授权；Stage5 尚未关闭，Stage5D 未开始。
