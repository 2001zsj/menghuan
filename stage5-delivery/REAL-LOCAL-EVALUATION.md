# 有限真实候选本地评估

本轮仅为内部、非商业、单次来源观察及本机采用验证。公共用途、商业用途和部署均未获准。旧合成入口保持独立并拒绝真实候选。

## 类型和数据库边界

- `synthetic-test`：既有人工映射合成演示；public schema。
- `synthetic-path-test`：自行编写内容经过真实候选契约和本地采用路径，不是真实来源证明。
- `real`：唯一批准响应的最小观察。后两者在本批 `stage5_real` schema；会话不得混用性质。
- 迁移前、会话前和事务写入前核对实际库名、loopback 地址、17.10；真实入口还须匹配显式配置的完整库名和存储 namespace。
- `0003_real_review.sql` 为新增独立迁移，旧 SQL/down 不变。回滚只删除专用 namespace，不删除基础业务表。
- 新临时实体仅代表一个已审核的完整条目边界，不是全局或官方身份。来源 ID 继续为空。相同标题无法区分则 pending。
- 保存、映射和采用为不同操作。映射不得自动采用；冲突不得覆盖。观察、快照、内部作品和审核决定分别标识。
- 七项字段：标题、日期、时间、时区、年份、季度、时间状态。每项 raw/normalized 值必须与当前字段一致；保存时只验证，不修补或自动改写。
- 来源默认关闭；到期拒绝新写入并隐藏页面。关闭保留已采用值；撤回仅移除所属贡献；清理同时删除候选、历史、贡献、实体及身份工作单。

## 本地 CLI

固定 Node 24 / pnpm10.34.5，环境 `APP_ENV=local`，旧合成和审核模式均 off。显式配置 `MENGHUAN_REAL_REVIEW_MODE=local-evaluation`、loopback 专用 `MENGHUAN_REAL_REVIEW_DATABASE_URL` 和 `MENGHUAN_REAL_REVIEW_SESSION_ID`。

```text
pnpm --filter @menghuan/database exec tsx src/cli/real-review.ts <操作与参数> --local-evaluation
```

1. `init`：建立默认关闭、最长七天范围。不请求来源。
2. `on`：显式启用本地会话；`off` 不清空已采用字段。
3. 合成路径测试另加 `--synthetic-path-test` 并执行 `fixture-load`；真实会话拒绝该操作。
4. `list`：列出当前观察/实体版本、摘要及采用字段。真实记录的 UUID/摘要仍属私有工作单，不进入脱敏交付。
5. `inspect <观察ID>`：只供本地私有审核。输出包含最小真实值，不得保存进源码或证据包。
6. `entity <观察ID> <real-local-UUID> <建档依据>`：临时实体只含已明确审核的标题，其他字段保持未知。
7. `map <决定ID> <观察ID> <观察版本> <摘要> <实体ID> <实体版本> <项目锚点> <理由> <证据> [替代决定ID]`。
8. `adopt <采用ID> <映射ID> <观察版本> <摘要> <实体版本> <逗号分隔字段> <理由> [resolve]`。`resolve` 必须是新的明确审核决定，不能重用旧 ID。
9. `hold/reject <观察ID> <理由>`；`withdraw <映射ID> <理由>`；`purge` 在撤回后删除当前会话全部值副本。

无任意文件/URL导入、公开审核 API、GET 命令或定时同步。真实传输只由本任务的受控执行脚本调用正式 Worker 显式 direct 模式；持久预算预先扣除，一次失败不再尝试。20秒、1MiB、零重试/重定向/子资源，解析前三条，HTML仅内存。
